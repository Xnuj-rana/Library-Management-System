# 📚 Library Management System in C++

A Interesting, menu-driven **Library Management System built using C++ and Object-Oriented Programming (OOP)**. This beginner-friendly project allows users to add, search, issue, return, and display books through a simple console interface.

## ✨ Features

- ➕ Add new books
- 📖 Display all books
- 🔍 Search books by ID
- 📤 Issue books
- 📥 Return books
- 📊 Check book availability
- 🧑‍🎓 Display student profile
- 👨‍💼 Display librarian profile
- 🎨 Colorful terminal interface
- 📦 Store up to 100 books using arrays

## 🛠️ Technologies Used

- C++
- `iostream`
- `string`
- `iomanip`

## 🧠 OOP Concepts Used

| Concept | Implementation |
|---|---|
| Classes and Objects | `Book`, `Library`, `Person` |
| Encapsulation | Private book details |
| Constructors | Initialize objects |
| Inheritance | `Student` and `Librarian` inherit from `Person` |
| Arrays | Store book records |
| Loops and Conditions | Search, issue, return, and display books |
| Switch Statement | Menu-driven interface |

## 🚀 How to Run

**Step 1:** Install a C++ compiler such as GCC.

**Step 2:** Clone or download this repository.

**Step 3:** Open the project folder in VS Code.

**Step 4:** Open the terminal and compile the program:

```bash
g++ main.cpp -o library.exe
```

**Step 5:** Run the program on Windows:

```powershell
.\library.exe
```

## ⚠️ Limitations

- A maximum of 100 books can be stored.
- Book records are stored temporarily in an array.
- All book records are lost when the program closes.
- Student and librarian profiles are sample profiles.
